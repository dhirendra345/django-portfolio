# Django Full Stack Portfolio Website

A full stack portfolio website built using Django, PostgreSQL, REST API, Authentication, Email Integration, and Admin Dashboard.

---

## 🚀 Features

### Public Portfolio
- Home page with introduction and skills
- About page with education, achievements, and profile image
- Projects listing with slug-based detail pages
- Contact form with email notification

### Authentication System
- User registration
- Login and logout
- Admin-only dashboard
- Role-based access control

### Projects Management
- Slug-based routing
- Admin-only project creation
- CRUD operations
- Ordered by creation date

### Contact System
- Stores messages in database
- Sends email notification to admin
- Messages visible in admin dashboard

### REST API (Django REST Framework)
- GET all projects
- GET single project by slug
- POST project (admin only)
- POST contact message

### Database
- PostgreSQL integration
- Django ORM
- Migrations applied
